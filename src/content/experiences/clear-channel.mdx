## Contexte et enjeux

Clear Channel France est un acteur de l'affichage publicitaire. Le projet était mené **à l'international**, avec une équipe répartie entre Paris et Londres : le travail se faisait en anglais. Le projet consistait à **prototyper un outil d'analyse de données publiques externes**, accessibles au travers d'API, en complément des données internes.

- **Collecter en continu** des données externes, comme le trafic en temps réel, sans intervention manuelle.
- **Réunir** ces données et les données internes dans une même base.
- **Les rendre exploitables** : une carte et des tableaux plutôt que des données brutes.

## Architecture

Une tâche planifiée hébergée sur **AWS** interroge régulièrement les API externes, TomTom pour le trafic et Google Maps, et stocke les données dans **MongoDB Atlas** avec les données internes. Une **API Node.js** les expose ensuite à l'application **React**.

## Ce que j'ai fait

- **Backend** Node.js : API répondant aux besoins des fonctionnalités du front.
- **Front** React : affichage des données sur une **carte interactive Leaflet** et dans des tableaux.
- **Collecte automatisée** : script JavaScript hébergé sur AWS et exécuté par une tâche planifiée (cron), qui récupère les données de trafic en temps réel.
- **Modélisation** des données NoSQL dans MongoDB Atlas.
